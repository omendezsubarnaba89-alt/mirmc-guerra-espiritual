# MIRMC Guerra Espiritual

Experiencia web de formación bíblica, enseñanza y recursos para comprender la guerra espiritual con **Cristo como centro**.

## Primera versión

La web incluye:

- Portada cinematográfica responsive.
- Navegación para móvil y escritorio.
- Fundamentos: identidad, discernimiento y autoridad bajo Cristo.
- Armadura de Dios interactiva basada en Efesios 6:10–18.
- Ruta de entrenamiento en tres niveles.
- Biblioteca de recursos preparada para crecer.
- Animaciones, partículas y soporte para `prefers-reduced-motion`.
- Diseño sin backend ni servicios de pago en esta primera etapa.

## Archivos principales

- `index.html` — estructura y contenido.
- `styles.css` — identidad visual y responsive design.
- `script.js` — interacciones, armadura, menú y partículas.

## Publicar en GitHub Pages

Este proyecto está preparado para servirse directamente desde la rama `main`.

En GitHub abre **Settings → Pages** y en **Build and deployment** selecciona:

1. **Source:** Deploy from a branch.
2. **Branch:** `main`.
3. **Folder:** `/ (root)`.
4. Guarda los cambios.

La URL esperada será:

`https://omendezsubarnaba89-alt.github.io/mirmc-guerra-espiritual/`

## Dirección del proyecto

La meta es convertir esta primera landing page en un ecosistema de formación con cursos, biblioteca, progreso, recursos para líderes y experiencias interactivas, manteniendo siempre la Escritura y la obra de Cristo como fundamento.
