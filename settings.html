MIS DATOS

Tu progreso debe poder viajar contigo.

Mientras no exista una cuenta sincronizada, puedes guardar una copia de tu progreso y restaurarla en este u otro navegador.
01

Exportar respaldo

Descarga un archivo JSON con Guardia, lecciones, evaluaciones finales y nombre del certificado.

02

Restaurar respaldo

Selecciona un respaldo generado por esta plataforma. Antes de escribir datos se valida su estructura.

03

Instalar la aplicación

Cuando tu navegador lo permita, instala MIRMC Guerra Espiritual en la pantalla de inicio para abrirla como una app.

También puedes usar el menú de Chrome → Añadir a pantalla de inicio.
04

Restablecer datos locales

Elimina Guardia, curso, exámenes y nombre del certificado en este navegador. Esta acción no se puede deshacer sin un respaldo.

Privacidad local

En esta etapa MIRMC no recibe este progreso en un servidor. El archivo de respaldo puede contener tu nombre si lo escribiste para el certificado; guárdalo donde consideres seguro.
