Privacidad y seguridad

Cuando la nube esté activa, el navegador utiliza una clave publicable y una sesión de usuario. Las políticas de Row Level Security de la base de datos son las que limitan cada fila al dueño autenticado; las claves administrativas nunca pertenecen al frontend.
